# Meta広告（Instagram / Facebook）の月替わり手順とチェック

2026-10 に「広告に出ている画像が指定の10月バナーではなく、室内ブースの写真になっていた」事故があった。
原因は、LPに og:image（リンクプレビュー画像）の指定がなく、広告の画像がバナーと別の場所から決まっていたこと、
そして「広告に実際に出ている画像」を誰も見ていなかったこと。再発防止として、画像の元を1か所にし、
毎週「お客様に見えている画像」を確認して記録する。

## 正しい状態（毎月これが揃っていること）
1. `src/banner.json` の `month` が今月。`og_image` が今月のバナー（`banners/YYYY-MM.jpg`。2026-10 は `banners/LINE_NOTE_260903_10.jpg`）
2. LPのヒーロー画像（`src/assets/out_hero.jpg`）が同じバナー（〆切日が今月末）
3. 広告マネージャの配信中の広告の画像が同じバナー。Instagramで実際に見た広告の画像も同じ
4. 広告の画像は「バナー1枚」だけ。複数画像・Advantage+クリエイティブの「画像の自動差し替え／背景生成／画像の拡張」はオフ
5. 広告の「クリエイティブの設定 → ウェブサイトのハイライト → 画像」がオフ（オンだとLP内の施設写真が勝手に広告画像として使われる。2026-10の事故の直接原因）

## 月替わりの手順（新しいバナーをLINEで受け取ったら。遅くとも毎月1日まで）
1. 受け取ったバナーを `banners/` に保存（LINEは「オリジナル画質」で保存。幅1000px未満なら受け取り直す）
2. `python src/set_banner.py banners/<保存した.jpg> --month YYYY-MM` → ヒーロー画像・OG画像・banner.json が一度に更新される
3. `node src/build.cjs` → `git add -A` → commit → push（build は banner.json の月が今月と違うと止まる）
4. 広告マネージャ（https://adsmanager.facebook.com/ ）で配信中の広告を開き、画像を `banners/YYYY-MM.jpg` に差し替える。
   広告セット・広告が複数あればすべて。差し替え後の「広告プレビュー → Instagramフィード」をスクリーンショットで確認
5. Metaのシェアデバッガー（https://developers.facebook.com/tools/debug/ ）に `https://golfprime-nishiinter.github.io/` を入れて「もう一度スクレイピング」。
   プレビュー画像が新バナーになっていることを確認（Metaはリンクプレビューを数週間キャッシュする）
6. 下の「確認ログ」に1行書く

## 広告の月替わり（毎月1日に、確認なしで行う。康太さん指示 2026-11-02「広告の差し替えを自動で予定通りやって。次回からも自動で」）
Meta広告は月末で配信が終わる（10月広告は10/31終了）。毎月1日に、前月の広告をもとに今月分を作って配信を始める。
この作業は定期タスク golfprime-sns-post の1日の回（21時）で行う。1日に動けなかった場合は、最初に動いた日に行う。
**変えてよいのは「画像」「配信期間」「月の表記」だけ。予算・ターゲット・配置・リンク先は前月と同じにする。予算を上げる／下げる・新しいターゲットを試すのは康太さんの指示があるときだけ。**

前提: `src/banner.json` の `month` が今月で、LP（https://golfprime-nishiinter.github.io/ ）のヒーローが今月のバナーになっていること。なっていなければ先に上の「月替わりの手順」1〜3を行う（`banners/` に今月のバナーが無ければ康太さんに「今月のバナーをLINEで送ってください」と連絡して、届くまで広告は作らない。前月のバナーで配信してはいけない）。

1. 広告マネージャ（https://adsmanager.facebook.com/ ）で広告アカウント「Golfprime西インター店」を開き、「キャンペーン」タブで前月のキャンペーン（配信終了済み）を見つける
2. 前月のキャンペーンにチェック → 「複製」→ 元のキャンペーンと同じ広告セット・広告を含めて複製（「下書きとして作成」）
3. 複製したキャンペーン名の月を今月に直す（例: 「10月キャンペーン」→「11月キャンペーン」。元の名前の付け方に合わせる）
4. 広告セット: 配信期間を「今日（1日）0:00 〜 今月末日 23:59」にする。1日より後に作る場合は開始を今から。**日予算は前月と同額**（変えない）。ターゲット・配置は複製のまま
5. 広告: 画像を `banners/YYYY-MM.jpg`（今月のバナー）に差し替える。アスペクト比ごとの切り抜きがある場合は、縦長(4:5)・正方形(1:1)・ストーリー(9:16)すべて同じバナーにする。
   「クリエイティブの設定」で **ウェブサイトのハイライト → 画像 をオフ**、Advantage+ クリエイティブの画像生成・背景生成・画像の拡張は**すべてオフ**。見出し・本文に前月の月名や日付があれば今月に直す（例: 「10月31日まで」→「11月30日まで」）。リンク先は https://golfprime-nishiinter.github.io/ のまま
6. 「広告プレビュー → Instagramフィード」「Instagramストーリーズ」「Facebookフィード」を見て、すべて今月のバナーだけが出ていることをスクリーンショットで確認
7. 「公開する」。審査が終わるまで「審査中」になる。翌日の回で「配信中」になったか確認する
8. 下の確認ログに1行書き、康太さんに「◯月の広告を作って公開しました（予算は前月と同じ◯円/日、◯/◯〜◯/◯）」と報告する
9. 前月のキャンペーンは**削除しない**（数字の比較に使う）。オフのままにしておく

うまくいかないとき: 前月のキャンペーンが見つからない／予算の入力を求められて前月の額が分からない／審査で否認された、のどれかなら、スクリーンショットを添えて康太さんに聞く。推測で予算を決めない。

## 毎週の確認（定期タスク golfprime-sns-post が月曜に行う。手順は sns/README.md）
- 広告マネージャで**今月の広告が配信中か**を見る。配信中の広告が0件（前月分が終了したまま）なら月替わりが未実施なので、その場で上の「広告の月替わり」を行う
- 配信中の広告の画像を見て、`src/banner.json` の `og_image` と同じ画像か確認する（〆切日の文字を読み比べる）
- 違っていたら、その場で上の手順4〜5を行い、康太さんに「広告の画像が違っていたので直した」と報告する
- 月の最終週（25日以降）に翌月のバナーがまだ無ければ、康太さんに「翌月のバナーをLINEで送ってください」と依頼する
- 結果を下の確認ログに書く（1行）
