# Meta広告（Instagram / Facebook）の月替わり手順とチェック

2026-10 に「広告に出ている画像が指定の10月バナーではなく、室内ブースの写真になっていた」事故があった。
原因は、LPに og:image（リンクプレビュー画像）の指定がなく、広告の画像がバナーと別の場所から決まっていたこと、
そして「広告に実際に出ている画像」を誰も見ていなかったこと。再発防止として、画像の元を1か所にし、
毎週「お客様に見えている画像」を確認して記録する。

## 正しい状態（毎月これが揃っていること）
1. `src/banner.json` の `month` が今月。`og_image` が今月のバナー（`banners/YYYY-MM.jpg`。2026-10 は `banners/LINE_NOTE_260903_10.jpg`）
2. LPのヒーロー画像（`src/assets/out_hero.jpg`）が同じバナー（〆切日が今月末）
3. 広告マネージャの配信中の広告の画像が同じバナー。Instagramで実際に見た広告の画像も同じ
4. 広告の画像は「バナー1枚」だけ。複数画像・Advantage+クリエイティブの「画像の自動差し替え／背景生成／画像の拡張」はオフ

## 月替わりの手順（新しいバナーをLINEで受け取ったら。遅くとも毎月1日まで）
1. 受け取ったバナーを `banners/` に保存（LINEは「オリジナル画質」で保存。幅1000px未満なら受け取り直す）
2. `python src/set_banner.py banners/<保存した.jpg> --month YYYY-MM` → ヒーロー画像・OG画像・banner.json が一度に更新される
3. `node src/build.cjs` → `git add -A` → commit → push（build は banner.json の月が今月と違うと止まる）
4. 広告マネージャ（https://adsmanager.facebook.com/ ）で配信中の広告を開き、画像を `banners/YYYY-MM.jpg` に差し替える。
   広告セット・広告が複数あればすべて。差し替え後の「広告プレビュー → Instagramフィード」をスクリーンショットで確認
5. Metaのシェアデバッガー（https://developers.facebook.com/tools/debug/ ）に `https://golfprime-nishiinter.github.io/` を入れて「もう一度スクレイピング」。
   プレビュー画像が新バナーになっていることを確認（Metaはリンクプレビューを数週間キャッシュする）
6. 下の「確認ログ」に1行書く

## 毎週の確認（定期タスク golfprime-sns-post が月曜に行う。手順は sns/README.md）
- 広告マネージャの配信中の広告の画像を見て、`src/banner.json` の `og_image` と同じ画像か確認する（〆切日の文字を読み比べる）
- 違っていたら、その場で上の手順4〜5を行い、康太さんに「広告の画像が違っていたので直した」と報告する
- 月の最終週（25日以降）に翌月のバナーがまだ無ければ、康太さんに「翌月のバナーをLINEで送ってください」と依頼する
- 結果を下の確認ログに書く（1行）
